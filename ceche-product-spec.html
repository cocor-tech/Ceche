Product Specification · v1.0

Ceche — Domain Appraisal Engine

A 15-module scoring architecture for valuing any domain string — registered or unregistered — with zero bias toward domains that already have history. Built entirely on free-tier and self-hosted tooling for a $0–$2/month operating budget.

MODULES 15
MONTHLY COST $0.00
SIGNUP REQUIRED 7 of 15
PAID API KEYS 0

How to read this document

Each of the 15 modules below is a self-contained tool your AI agent calls. Every one is tagged by cost model:

Free API — genuinely free, no card, callable programmatically, no manual step. Manual lookup — free, but requires the agent (or you) to browse/read a page rather than call a clean API. Fine at low volume, per your note. Self-hosted — runs on your own machine/server, zero third-party cost.

The 15 modules

Full detail: what each tool does, exactly which free service or library covers it, and the direct signup link.

01

WHOIS / RDAP Lookup + Cross-TLD Check

Registration status, domain age, registrar, expiry — plus checking whether the same string exists on other TLDs.

Free APINo signup
Tool
RDAP (Registration Data Access Protocol) — the ICANN-mandated free successor to WHOIS.
Signup
rdap.org — no account, no key. Query directly or via bootstrap endpoints.
Notes
Run this same query per candidate TLD (.com, .net, .co, .xyz etc.) — one call type covers both registration status and the cross-TLD conflict check.
02

TLD Score Table

A static lookup table ranking each TLD's baseline market value (.com highest, down to low-value new gTLDs).

Self-builtNo signup
Tool
No API — a table you build and update yourself, seeded from public comparable-sales data.
Source data
NameBio.com — free, browsable public sales history, no login required to view.
Notes
Revisit quarterly — TLD standing shifts (e.g. .ai's premium rose sharply in recent years).
03

Character Length Scorer

Raw character count → score. Shorter scores higher, independent of word count.

Local codeNo signup
Tool
Pure computation — len(domain_string) mapped through a scoring curve you define. No external dependency at all.
04

Word-Count Scorer

Separate from length: 1 real word scores higher than 2, which scores higher than 3+.

Local codeNo signup
Tool
Not a standalone API — reads the word_count field from Module 6's winning segmentation and applies a penalty curve.
05

Pronounceability Scorer

Separates "yotop" (sayable) from "fjfbfj" (not) — before any dictionary lookup happens.

Free libraryNo signup
Tool
CMU Pronouncing Dictionary + pyphen for syllable/phonetic pattern checks. Both run locally, fully open-source.
Install
pypi.org/project/pyphen · nltk.org (bundles the CMU dict corpus)
06

Segmenter — Multi-Way Split Engine

Breaks a string into every valid 1-, 2-, and 3+-word reading (e.g. "beastar" → "be"+"a"+"star" AND "beast"+"ar"), scores each candidate, and surfaces the strongest plus alternates.

Free libraryNo signup
Tool
wordfreq package for word-frequency weighting, combined with a dynamic-programming word-break algorithm over a common-word list.
Install
pypi.org/project/wordfreq · word list: github.com/first20hours/google-10000-english
Notes
No valid split found → hands off cleanly to Module 5's pronounceability score instead of scoring zero.
07

Keyword Popularity Lookup

Per-segment search interest — tells you if "top" is a popular term and "fjfbfj" is not.

Free, unofficialNo signup
Tool
pytrends — an unofficial Python wrapper around Google Trends. Returns relative interest over time per term.
Install
github.com/GeneralMills/pytrends
Manual fallback
trends.google.com — agent can browse directly if the library gets rate-limited.
Caution
Scrape-based, not an official API — expect occasional rate-limit blocks. Route through the caching layer (Module 14) aggressively.
08

CPC / Commercial-Intent Scorer

Distinguishes a searched-but-informational term (e.g. "sad") from a genuinely valuable commercial one (e.g. "insurance").

Manual lookupFree signup
Tool
Bing Webmaster Tools' Keyword Research feature — free once you have a Microsoft account, gives volume + CPC-adjacent competition data.
Signup
bing.com/webmasters
Alt. manual option
Ubersuggest's free Chrome extension (40 lookups/day, no paid plan needed): neilpatel.com/ubersuggest/extension
Note
This is the one honest gap in the free stack — there is no clean free API for CPC data. Treat it as agent-assisted manual lookup until you can afford a real key (Google Ads API or DataForSEO).
09

Search-Results Checker

Searches the full domain string and reads the pattern: many related results → established concept; scattered unrelated results → brandable coinage; a competing TLD variant actively ranking → conflict flag.

Free tierSignup required
Primary tool
Google Programmable Search Engine (Custom Search JSON API) — 100 free queries/day.
Signup (1/2)
programmablesearchengine.google.com — create a search engine scoped to the whole web.
Signup (2/2)
developers.google.com/custom-search/v1 — generate the API key.
Backup tool
Brave Search API — independent index, roughly 1,000 free queries/month. Signup: brave.com/search/api
Correction
Bing's Web Search API — mentioned earlier in this build-out — was fully retired by Microsoft on August 11, 2025, with no new signups possible. It is not a usable option anymore; Google CSE + Brave replace it above.
10

Direct Cross-TLD Parked-Variant Check

Distinct from trademark risk: flags whether a stronger-TLD variant of the same string is sitting parked, which could outrank you later if it wakes up.

Reuses Module 1No signup
Tool
Same RDAP calls as Module 1, run against every common TLD variant, plus a lightweight HTTP GET/HEAD request to detect parked-page vs. live-content vs. no response.
11

12

Backlink / History / Age Checker

Only activates for domains with prior use: backlink profile, authority, content history, prior penalties. Returns null cleanly for unregistered strings — never estimated.

Free APISignup required
Content history
Wayback Machine CDX API — fully free, no key. archive.org/help/wayback_api.php
Authority metric
Moz API — free tier with a limited number of calls/month. moz.com/products/api
Age
Already available from Module 1's RDAP creation-date field — no extra tool needed.
13

Confidence / Data-Completeness Flag

Tags every appraisal with which modules returned real data vs. hit a quota or returned null — so a missing signal is never silently scored as zero.

Local logicNo signup
Tool
Internal code — no external dependency. Each module call returns a status alongside its value; this module aggregates those statuses into one completeness score per appraisal.
14

Caching Layer

Caches lookups by term/segment, not by full domain — since fragments like "top," "shop," "get" repeat across thousands of queries and would otherwise burn free-tier quotas fast.

Self-hostedNo signup
Recommended for MVP
SQLite — built into Python, zero hosting cost, zero setup. sqlite.org
Upgrade later
Redis, once call volume justifies a dedicated cache process. redis.io (self-hosted, free open source)
15

Pricing / Valuation Module

Converts the aggregate score into an actual dollar estimate, anchored against real comparable sales. Planned in more depth separately, per your note — this is the free starting point.

Manual lookupNo signup
Tool
NameBio's public sales database — browsable free, no login. No API without their paid data export, so for now the agent (or you) manually pulls comparable sales by keyword/length/TLD.
Link
namebio.com
Later
Once revenue allows, an Estibot or DataForSEO comparable-sales feed replaces this manual step — not needed for v1.

Recommended build order

Sequenced by dependency and by which modules unlock the most scoring accuracy earliest.

  1. WHOIS/RDAP (01) + caching (14)Every other module depends on knowing registration status first, and caching should exist before you start hammering free-tier quotas.
  2. Length (03), word-count (04), pronounceability (05), segmenter (06)Pure local code and libraries — build these together since they share the same string-analysis input.
  3. TLD table (02) + cross-TLD checks (01/10)Static table plus the RDAP variant sweep — cheap to add once RDAP is working.
  4. Keyword popularity (07)pytrends integration — the first external signal that meaningfully separates real from junk domains.
  5. Search-results checker (09)Sign up for Google CSE + Brave now, since quota approval/setup takes a few minutes and is worth doing early.
  6. Trademark check (11)Free, no key, high value for risk-flagging — slot in right after search-results.
  7. CPC/commercial-intent (08) + backlink/history (12)The two manual/signup-gated modules — build last since they're the most fragile (rate limits, manual browsing) and least urgent for a first working demo.
  8. Confidence flag (13) + pricing module (15)Wrap everything with completeness scoring and the comparable-sales anchor once all data sources are live.

On the $2/month ceiling: nothing in this build requires payment. The two "manual lookup" modules (08 and 15) are the honest trade-off for staying free — they trade a clean API for agent-driven browsing. Both have a straightforward upgrade path (Google Ads API / DataForSEO for #8, Estibot / DataForSEO for #15) whenever the tool starts generating revenue.

On rate limits: pytrends (07) and the free search tiers (09) are the two most likely to throttle under real usage. The caching layer (14) exists specifically to keep repeat segment lookups ("top," "shop," "get") from burning quota on every single domain check.
